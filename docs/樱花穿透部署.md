# 异地组网：樱花穿透（T11 第一部分）

> **结论先说**：穿透**不需要改任何代码** —— 你要的"开一个端口、另一端连"就是它。
> 真正要小心的是**一处**：配对二维码里装的 ws 地址必须是**手机能访问到的那个**（公网地址），
> 而不是 `127.0.0.1` / 局域网 IP。这一处已经补好了。

---

## 一、拓扑

```
被控者手机 DG-LAB App ──扫码──┐
                              │
                    樱花穿透  │  公网 xxxxx.natfrp.com:<公网端口>
                              │        ↕（隧道）
                    ┌─────────┴──────────┐
                    │  被控端机器         │
                    │  python tools\relay.py  监听 :9997
                    └────────────────────┘
                              ▲
                              │ ws://xxxxx.natfrp.com:<公网端口>
                    控制端 coyote_v4（agent/config.toml）
```

**注意方向**：中继（relay）跑在**被控端**；控制端**连它**。
（反过来也行，只要两边 config 对上；但手机 App 必须能访问中继的那个地址。）

---

## 二、步骤

### 1. 被控端：起中继（**记下它打印的房间口令**）

```powershell
python tools\relay.py --host 0.0.0.0 --port 9997
# 输出里会有一行：★ 房间口令：AB12CD
```

### 2. 樱花：开一条隧道

在樱花面板建一条 **TCP 隧道**：本地 `127.0.0.1:9997` → 它会分给你一个
公网地址（形如 `xxxxx.natfrp.com:<公网端口>`）。**只要这一条**，别的都不用动。

### 3. 控制端：把 url 指向公网地址

`agent/config.toml`：

```toml
[coyote_v4]
url = "ws://xxxxx.natfrp.com:<公网端口>?room=AB12CD"
```

启动后它会连上中继并拿到 `targetId`（日志里会打）。

### 4. 控制端：出配对二维码（**这一步最容易错**）

```powershell
python tools\dev\coyote_lab.py --lan --public-host xxxxx.natfrp.com --public-port <公网端口> --room AB12CD
```

- `--lan`：让中继监听 `0.0.0.0`
- `--public-host` / `--public-port`：**二维码里装的地址** ——
  不填就自动取局域网 IP，那手机（在外网）扫了就连不上。
- `--room`：**必须与中继那个口令一致**（二维码里会自动带上）。

终端会把二维码直接用半块字符画出来，**手机 DG-LAB App 扫它**即可。

### 5. 被控者手机扫码接入

App 扫到 → 连上公网地址 → 与控制端配对 → 开火/波形/强度全都走这条隧道。

---

## 三、为什么二维码地址必须手动填

配对二维码的内容是
`https://dungeon-lab.cn/s/?v=1&action=socket&url=<ws地址>`（官方规定的跳转格式，
见 `agent/nodes/coyote_v4/pairing.py`）。App 扫完会**直接去连那个 `<ws地址>`**：

- 局域网演示：自动取本机局域网 IP ✅（`tools/dev/coyote_lab.py` 的 `lan_ip()`）
- 异地：必须是对端能访问的公网地址 —— 也就是樱花分配的那个。

**填错的症状**：二维码扫得出来、App 也能识别，但一直连不上（因为它在连一个它网络里不存在的 IP）。

## 四、安全：**房间口令（`?room=`）**

- ✅ **已加**：`tools/relay.py --room AB12CD`（不给会自动生成一个并打印）。
  给了就要求**两端连接都带** `?room=<口令>`，否则**直接拒连**（close 4403）。
  - 控制端：`url = ws://…:9997?room=AB12CD`
  - 手机 App：扫**控制端打印的配对二维码** —— 码里**自动带了 room**
    （`coyote_lab.py --room AB12CD`），用户不用手填。
- 这样一来，端口即使穿透到公网也不是裸奔：**口令不对连不上**。
- 还能继续叠加（纵深防御）：
  - 中继只在需要时开、用完就关；
  - bridge 层的 AEAD（`[bridge] encrypt = true`，见 `agent/nodes/bridge/README.md`）；
  - 樱花账号自己的访问控制 / 白名单。
- ⚠️ **口径别搞错**：room 是**明文放在 URL query** 里的，能挡"陌生人乱连"，
  **不等于端到端加密**。要防窃听得用 `wss`（给中继套 TLS）或 bridge 的 AEAD。
- README 里说的"能看到是谁访问了"属于 T11 的第二部分，**目前还没做**。
