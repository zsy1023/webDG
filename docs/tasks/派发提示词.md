# 派发提示词（主 agent → 各开发 agent）

> **用法**：把下面「通用约定」+ 对应任务的提示词**一起复制**给一个新的 agent 会话即可。
> 整体任务书在 `docs/tasks/T*.md`，本文件只是"派发时用的开场白"。

---

## 一、派发顺序（重要）

```
第 1 批（必须先做）：TF 节点框架
        ↓  TF 完成后
第 2 批（可同时派）：T2 感知组 ∥ T4 郊狼V4 ∥ T1 模拟郊狼（§9 验证）
        ↓
第 3 批：T3 桥接 ∥ T5 面板
```

**为什么 TF 必须先做**：所有节点都继承它的 `Node` 基类、都用它的 `topics.py`。
TF 没完成，其他 agent 写的节点**无法联调**（但可以先写业务代码）。

**并行派发时**：每个 agent 的 `write_paths` 不能重叠（见 `docs/tasks/README.md` §五）。
