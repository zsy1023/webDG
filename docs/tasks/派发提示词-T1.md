## 0. 一句话目标

让**控制者手机的 DG-LAB App 像连真硬件一样**操作我们的"假郊狼主机"，并把截获的指令
结构化地流到 `command/pulse_raw` 给 `coyote_v4` 消费：

```
控制者手机 App ──BLE──> ESP32（假主机，复刻真机 GATT + 广播名 47L121000）
                            │ 串口 / TCP（帧协议见 §4）
                            ▼
                     agent/nodes/sim_coyote（PC 侧，已有一半）
                            │ command/pulse_raw（本机 Zenoh）
                            ▼
                        coyote_v4 ── device.op ──> 被控端
```

你负责：**① ESP32 固件** 与 **② PC 侧链路实现**。协议编解码**已经写好，别重写**。

**关键实测结论（照做，不要照官方文档改）**：

1. `0x150A` 是 **`WriteWithoutResponse`**（官方文档写 WRITE，是错的）；
2. **只要 `B0` 的序列号 ≠ 0，主机就必回一条相同序列号的 `B1`** —— 哪怕强度没变
   （官方文档说"强度变化才回"，实测不符）；
3. 真机 `0x180A` 下除了 `0x1500` 还有 **`0x1501`（`0c 03`）/`0x1502`（本机 MAC）/`0x2A25`/`0x2A59`**，
   还有 `0x2003`/`0x2004`/`0xFE59`(DFU) —— App 初始化时会读/订阅它们。

> ⚠️ **Windows 路线已被实测否决**：`0x1800`/`0x1801`/`0x180A` 是系统保留服务，
> `GattServiceProvider.create_async` 一律返回 `DISABLED_BY_POLICY`（**无解**，官方文档确认），
> 且广播名只能是系统蓝牙名。**这就是为什么必须用 ESP32。**

## 3. 确认一个关键事实（**动手前先验**）

> **ESP32 能不能发布这些"保留服务"？**

能。ESP32 的 NimBLE/Bluedroid **没有 Windows 那套保留服务策略**，可以自由定义 GATT 表 ——
这正是选它的原因。但**请先用一块板子把 §6 的 A1~A3 跑通**，再往下做（别一口气写完才发现板子不对）。

## 4. 接口契约（**照这个实现，不要自己发明**）

PC 侧已经把契约写在 `agent/nodes/sim_coyote/transport.py` 的 `Esp32Peripheral` 类 docstring 里，
**以它为准**。摘要：

```
ESP32 → 主机（上行）            主机 → ESP32（下行）
0xB0 + 19B    B0 指令（20B）    0xB1 + 3B   B1 强度回包（4B）
0xBF +  6B    BF 指令（7B）     0xCE        心跳（可忽略）
0xCC          App 已连上
0xCD          App 已断开
```

**用 HEAD 字节区分帧型**（B0=20 / BF=7 / B1=4 都是定长，不需要长度前缀）。
App 的 B0/BF **原样透传**，不要解析后重组（解析是 PC 侧 `protocol.py` 的事）。

## 9. 已知风险（先看，别重复踩）

1. **App 可能对缺失特征敏感** —— 真机 `0x180A/0x1501` 是 App 判定 **V2/V3 协议**的依据，
   必须返回 `0c 03`；`0x2A59` 是**输出状态回读**（随 B0 波形变化），App 订阅了它。
2. **Windows 端订阅限制**：真机实测里 `0x1500`/`0x2A59` 在未加密链路上 `start_notify` 会被拒 ——
   ESP32 侧要确认 App 订阅这两个能不能成功（可能需要加密/配对）。
3. **广播内容**：真机空闲广播里**不带服务 UUID、也没有厂商数据**，只有名字。
   ESP32 侧可以先照这个来（名字 `47L121000` 是关键）。
4. `0x2A59` 的**精确编码规则仍未解出**（只知道它跟 B0 的波形走）——
   需要时用 `agent/nodes/sim_coyote/probe_full.py` 那类探针去真机上多试几组。
